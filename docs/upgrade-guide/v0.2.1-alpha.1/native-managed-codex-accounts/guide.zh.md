# 原生 Codex 托管账户

[English](guide.md) | 中文

## 变更

原生初始化器在隔离且可编辑的桌面配置中启用 `llm-pi-ai.nativeCodexAccounts`，并设置私有的 `nativeCodexVault`。不会导入已有旧凭据，也不会将其用作备用授权。之前启用的模型路由不代表允许使用尚未选择的托管账户。未启用托管模式的普通配置继续采用旧行为。

Add 保存尚未选择的账户。原生命令选择或删除账户时必须携带预期的选择 epoch；过期请求失败，不会改变当前选择。本地退出登录删除本地授权，但不向签发方撤销授权，也不选择其他账户。变更结果未知时必须显式读取状态，绝不自动重试。

## 迁移

1. 使用匹配的 alpha 后端与原生消费方。已安装运行时及其他配置保持独立。
2. 通过 Settings → Codex → Connect ChatGPT 显式登录。不要将旧凭据复制进托管授权存储。已有授权保持原样，不会被接收。
3. 其他账户通过 Add 添加，并显式审查、确认选择。遇到 `CODEX_EPOCH_CONFLICT` 时读取当前状态，重新取得用户决定。
4. 选择或退出登录的确认丢失后，先读取账户状态，再执行其他变更。不要假设退出登录已撤销签发方授权，或已断开运行中的外部客户端。

配置、存储所有权及限制见[提供方参考](../../../../packages/llm/llm-pi-ai/README.zh.md)。
